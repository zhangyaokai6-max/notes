      跨设备同步

      便签和任务会保存到你 GitHub 账号下的一个私密 Gist。每台设备连接一次，之后自动保持一致。

      1. 在 GitHub 创建一个只勾选 gist 权限的 token，复制它。
      2. 粘贴到下面，点“连接”。另一台设备上再做一遍这一步。

      Token 只保存在这台设备的浏览器里，不会写进 Gist。私密 Gist 不会被搜索到，但拿到链接的人可以打开，别在便签里放密码。连接以后，还可以开启日历订阅，让手机日历提醒截止和待办。

      上次同步

      在另一台设备打开这个网页，用同一个 GitHub 账号的 token 连接，就能看到同一份内容。

      每次同步时，把截止、待办、会议和里程碑生成一个日历文件，一起存进 Gist。手机和电脑的日历订阅下面的链接后，提醒就交给系统日历。

      放进日历的内容
      订阅链接
      用苹果日历订阅添加到 Google 日历
      各个日历怎么订阅、提醒会不会响
      • iPhone、Mac：点“用苹果日历订阅”，或者在日历里“添加订阅日历”，粘贴链接。不要勾选“移除提醒”；刷新频率选“每小时”。
      • 安卓：装 ICSx⁵（免费、开源），添加这个链接。日程会进系统日历（三星、小米、华为日历都能看到），提醒照常响。
      • Google 日历：网页版“其他日历 → 通过网址添加”。能看到日程，但订阅的日历一般不弹提醒，更新也可能要等几小时到一天。要提醒，安卓用 ICSx⁵，苹果设备用系统日历。
      • Outlook：“添加日历 → 从 Internet 订阅”。

      日历是只读的：要改日期就在这个网页里改，同步以后日历会跟着更新（多久刷新一次由日历 App 决定）。链接里带着 Gist 的编号，拿到链接的人能看到这些日程，不要公开分享。
